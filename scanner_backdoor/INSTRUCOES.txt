🔍 O QUE O SCANNER DETECTA
═══════════════════════════════════════════════════════════════════════════════

✓ Código XOR ofuscado
✓ Arquivos JavaScript ocultos (nomes começando com ponto)
✓ Arquivos com nomes suspeitos (ex: gitignore.js, gitattributes.js)
✓ Linhas maliciosas em fxmanifest.lua
  - Padrão: --[[server.lua]] seguido de muitos espaços e arquivo .js
  - Exemplo: --[[server.lua]]                                 'temp/.env.local.js'
✓ Padrões específicos de backdoor:
  - x=(e,k=3)=>[...e].map(c=>String.fromCharCode(c.charCodeAt()^k))
  - x=s=>eval(s.replace(/\\u([0-9a-f]{4})/g,...))
  - globalThis[x("fubo")]
  - Comentários /* [ nome_recurso ] */ seguidos de código ofuscado

📊 RELATÓRIO
═══════════════════════════════════════════════════════════════════════════════

O scanner gera um relatório em formato texto:
• Nome: relatorio_scan_YYYYMMDD_HHMMSS.txt
• Local: Mesmo diretório onde o scanner foi executado
• Conteúdo: 
  - Lista completa de arquivos JavaScript maliciosos encontrados
  - Lista de arquivos fxmanifest.lua com linhas maliciosas
  - Número de arquivos deletados
  - Número de linhas removidas
